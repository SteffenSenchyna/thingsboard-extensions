# ThingsBoard's own pages, dark (parked)

A dark theme for ThingsBoard's own pages (its entity tables, details panels, dialogs, settings, rule chain editor),
shown while the user's theme is dark and no dashboard is showing. Parked on 2026-11-12: it isn't in the live custom
CSS. The side nav, top bar and their menus still follow the user's theme on every page (`white-labeling/custom-css.scss`).

- `_dark.scss`: Material's controls from the app's dark tokens (`tb-dark-material`), then ThingsBoard's own colours
  (`tb-dark-thingsboard`).
- `_dark-generated.scss`: ThingsBoard's own colours re-mapped to the dark tokens, generated by `dark-overrides.py`
  from `dark-harvest.json` (collected on ThingsBoard's pages by `dark-harvest.js`).
- `enable.patch`: wires it back into `custom-css.scss`, `package.json` (the build's Material load path) and
  `CLAUDE.md`.

## Turn it back on

```bash
git apply white-labeling/dark-pages/enable.patch
```

```bash
yarn upload:white-label
```

The custom CSS grows from about 50 KB to about 224 KB. To turn it off again: `git apply -R white-labeling/dark-pages/enable.patch`,
then `yarn upload:white-label`.

## After a ThingsBoard upgrade

New ThingsBoard styles can bring light spots back. Run `dark-harvest.js` in the browser console on one of ThingsBoard's
pages (a tenant administrator's, not a dashboard): it opens each page of the side nav and saves `dark-harvest.json`.
Put that file here, then:

```bash
python3 white-labeling/dark-pages/dark-overrides.py
```
